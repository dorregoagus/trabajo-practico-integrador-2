# trabajo-practico-integrador-2
#Trabajo Práctico Integrador II

Frontend desarrollado con React para consumir el backend realizado en el Trabajo Práctico Integrador I.

Tecnologías utilizadas:
React
Vite
JavaScript
React Router
Tailwind CSS
Fetch API
ESLint

##Backend sacado del trabajo práctico integrador I
https://github.com/dorregoagus/trabajo-practico-integrador-1.git

###Funcionalidades:
Registro de usuarios.
Inicio y cierre de sesión.
Protección de rutas privadas.
Persistencia del estado de sesión mediante localStorage.
Consumo de la API mediante fetch.
Visualización de artículos.
Manejo de estados de carga y errores.
Navegación mediante React Router.
Diseño realizado con Tailwind CSS.
